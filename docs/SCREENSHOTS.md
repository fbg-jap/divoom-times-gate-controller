# Example screenshots · Keeper 3.1

[Back to the project](../README.md)

These are actual screenshots of the web interface in demo mode (English, sample names, metrics and content; no device and no credentials). They are generated by `tools/screenshots.mjs`. Screen previews are generated by the app; they are not photographs of the physical Times Gate. The phone-sized view is the portal in a 375 px wide browser window, not a validated Android/iOS installation.

**Retaking them:** `cd web && npm ci && node ../tools/screenshots.mjs [name ...]` (or `npm run screenshots`). The script starts the app with `--demo --minimized`, a temporary config folder and a free port, signs in with the one-time launch URL, loads demo content through the config API and saves the PNGs here. It uses the system browser: `brave-browser`, `google-chrome(-stable)`, `chromium(-browser)` or `microsoft-edge` from `PATH`, or `KEEPER_SCREENSHOT_BROWSER`; the app command can be changed with `KEEPER_SCREENSHOT_APP` (default `.venv-linux/bin/python app.py`, else `python3 app.py`).

The web interface has a single dark theme, so there is no light-theme screenshot.
