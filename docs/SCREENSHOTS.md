# Example screenshots · Keeper 3.1

[Back to the project](../README.md)

These are actual interface screenshots using demo settings, names, metrics and sample content. Screen previews are generated by the app; they are not photographs of the physical Times Gate. The phone-sized view is a browser preview, not a validated Android/iOS installation.

The desktop RGB screenshot shows **3.1.1**. The other examples were captured for **3.1.0** and still illustrate the corresponding features. Desktop screenshots use English (the desktop interface also supports Spanish through Settings); the web portal screenshots (RGB web and phone-sized view) have not been retaken yet and may still show Spanish.

## Five-screen layout

Clock, PC monitor, text, weather and network traffic, with independent content and colors.

![Five-screen layout](screenshots/screens.png)

## Desktop RGB

Desktop 3.1.1: preview, brightness, six presets, effects named by zone and a solid backlight color shortcut. [Behavior and firmware limits](RGB-3.1.1.md).
