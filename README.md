# Divoom Times Gate Controller · Keeper

Turn the five screens of your **Divoom Times Gate** into a display for images, animations, live data and notifications. Keeper sends content over **HTTP on your local network** and saves your layouts for recovery after a restart or disconnection.

**Windows · Linux · Web portal / Docker · Android · iOS**

**Desktop and Python server: 3.1.1. Shared web interface and standalone mobile apps: 3.1.0.** The latest desktop update adds named RGB effects for each lighting zone and a solid backlight color shortcut. The Python engine also fixes effect addressing and restores accepted lighting settings after reconnecting. [RGB guide and validation](docs/RGB-3.1.1.md).

## What you can do

| Feature | Purpose |
| --- | --- |
| **Five independent screens** | Combine images, GIFs and widgets; send one screen or the entire layout. |
| **Image, GIF and video panoramas** | Spread content across all five screens; choose the visible area, crop, zoom, rotate and trim animations. |
| **Per-screen playlists** | Alternate images and widgets with a separate duration for each item. |
| **PC monitoring** | Display CPU, RAM, available GPU metrics, graphs, network traffic, disks and available temperatures. |
| **Widgets** | Clock, text, weather, countdown, HTTP status, ICS calendar, RSS/Atom news, supported music sessions, Pomodoro and sensors. |
| **Visual designer** | Build screens with text, images, bars and dynamic fields; move and reorder layers. |
| **Scenes and schedules** | Save layouts, rotate scenes and schedule content, brightness or screen power changes. |
| **Automation** | Threshold alerts, reminders and profiles based on processes or session locking, where supported. |
| **Visual RGB lighting** | Choose colors, presets, brightness, zones and effects using swatches, sliders and cards. |
| **Integrations** | Local API, MQTT, Home Assistant and HTTP/MQTT sensor data. |
| **Portable backups** | Export and import settings, scenes, playlists and media in a ZIP file. |
| **Automatic recovery** | Keep the intended content and resend it periodically or when the device reconnects. |

Continuous tasks require the engine to stay running. The desktop app can stay in the system tray; Docker keeps working when you close the browser; mobile tasks depend on keeping the app active.

## Visual colors and RGB lighting

- A **16-color palette**, hue slider and saturation/lightness area.
- Recent colors during the session, with explicit confirm and cancel buttons.
- A preview of the selected **color, brightness and main lighting zone**.
- Six presets: **Ocean, Aurora, Sunset, Neon, Reading and Color cycle**.
- Twelve effect cards, with separate descriptive names for edges and backlight in desktop 3.1.1.
- A **Solid backlight color · no animation** shortcut that selects the rear zone and disables color cycling.
- Controls for lighting power, color cycling and key lighting.
- Settings saved per device after an accepted command. Choosing a swatch changes the preview; **Apply lighting** sends it.
- The visual color picker is also available in screen, playlist and layout editors.

![Desktop 3.1.1 RGB panel with named effects and a solid backlight color shortcut](docs/screenshots/rgb-desktop.png)

The web portal and mobile apps still label their cards **Effect 1–12**. The portal uses the corrected Python 3.1.1 engine; standalone mobile apps retain their 3.1.0 RGB implementation. The preview does not simulate firmware animations. Brightness and power are global, and selecting one zone can also affect the other. A custom solid color is supported by the documented rear-light mode; the steady edge color may be fixed by firmware. [Current RGB guide](docs/RGB-3.1.1.md) · [Web and mobile screenshots](docs/SCREENSHOTS.md).

## Adjustable and animated panoramas

Choose a local image, GIF or video and decide **which area to display**: drag the crop, move it horizontally or vertically, zoom or rotate by 90°. For animations, select the start, duration and FPS, play the preview or seek to a specific frame.

![Splitting a sample video into five animated panorama sections](docs/screenshots/panorama-video.png)

When applied, Keeper saves the previous layout as a scene and generates five files for the device. Videos are converted into silent animations; **live video streaming is not supported**. Uploads are sequential, so screens may start out of sync.

Limits: 100 MB per file, up to 30 seconds and 120 frames per screen. At 10 FPS, the maximum is 12 seconds. Codec support depends on PyAV/FFmpeg on desktop/server and on the phone for mobile conversion.

## Design your own screens

![Visual designer with dynamic text and a CPU bar](docs/screenshots/designer.png)

Combine text, images and bars with fields such as `{cpu}`, `{ram}`, `{time}` or `{date}`. The PC monitor includes graphs, networking, storage and temperatures; unavailable sensors display **N/D**. [More widget, playlist and automation examples](docs/SCREENSHOTS.md).

## Getting started

1. Connect your computer, server or phone to a network that can reach the Times Gate.
2. Open **Device** and enter its private IP address; desktop also offers LAN discovery. Newer firmware (hardware 402) also needs the **Local token** shown in the Divoom app under the device's settings; leave **Port** empty and Keeper finds it (80 or 9000).
3. In **Screens**, choose an image or widget and click **Save and send**.
4. Enable automatic updates for continuous widgets, playlists, schedules and notifications.
5. Save a scene or export a ZIP backup before trying a different layout.

Use one active controller per device to avoid competing screen updates. To switch the desktop UI to English, choose English in **Settings**.

### Windows from source

Python 3.11 or newer:

```powershell
git clone https://github.com/raishack/divoom-times-gate-controller.git
cd divoom-times-gate-controller
py -3 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe app.py
```

Explore the interface without sending to the device:

```powershell
./.venv/Scripts/python.exe app.py --demo
```

Build a portable executable:

```powershell
./build_windows.ps1
```

The output is in `dist/DivoomKeeperStudio/`. Copy **the entire folder**, including `_internal`; the compiled executable does not require a separate Python installation.

### Linux

```sh
bash run_linux.sh
# Try it without a device:
bash run_linux.sh --demo
```

Install the [Qt libraries and Linux prerequisites](docs/MULTIPLATFORM.md#linux-desktop) first (Debian/Ubuntu and Fedora commands are listed there). The script picks Python 3.13, 3.12 or 3.11 if available; set `PYTHON=python3.12` to choose one. Very new Python releases may not have PySide6 or PyAV wheels yet.

### Docker and web portal

```sh
docker compose up -d --build
docker compose exec keeper cat /data/admin.token
```

Open `http://SERVER_IP:8080` and enter the generated token. The volume preserves your data. You can also set `KEEPER_TOKEN` using `.env.example`. [Networking, authentication, backups and running without Docker](docs/MULTIPLATFORM.md#docker-and-web-portal).

### Android and iOS

```sh
cd web
npm ci
npm run build
npx cap sync
# Open the platform project you want to build:
npx cap open android
# On a Mac:
npx cap open ios
```

Android requires JDK 21 and SDK 36. iOS requires Xcode 26 and signing to install on an iPhone. [Mobile instructions and limitations](docs/MULTIPLATFORM.md#standalone-android).

## Migration, backups and compatibility

Keeper Studio stores data in `%APPDATA%/DivoomKeeperStudio/` on Windows, separate from the original app. Migration imports old profiles and copies available media without modifying v0.1.3 settings. Linux uses XDG paths.

Portable ZIPs include media, scenes and playlists. Import keeps a copy of the previous configuration and disables automatic sending so you can review the device. In the Python 3.1.1 engine, importing also pauses RGB restoration until you explicitly apply lighting again. Backups can move layouts between desktop, web and mobile, subject to platform differences.

Git history and the v0.1.3 release are preserved. To return to the original app, exit Studio, review its autostart setting and run the original executable. Private development backups and user data are excluded from the repository.

## Development

```sh
python -m pip install -r requirements.txt -r requirements-server.txt httpx
python -m unittest discover -s tests
cd web
npm ci
npm test
npm run build
```

Generate desktop demo screenshots with `python app.py --screenshot-dir artifacts/ui`. The portal's `?mobile-demo=1` mode runs the mobile engine with IndexedDB and simulated sends.
